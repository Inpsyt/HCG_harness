# ax-wireframe — Components

`:: component`(1:7)와 hi-fi(58:9)에서 반복되는 컴포넌트 패턴. 새 화면은 이 조합으로 짠다.

## 전역
- **GNB(헤더)**: 풀블리드, 좌 로고(HCG 워드마크) + 내비 + 우 액션(검색 아이콘·로그인·회원가입 다크버튼).
  하단 1px 라인. 활성 메뉴는 SemiBold+INK.
- **푸터**: 다크(`#0A0A0A`), 좌 로고+저작권, 우 3~4개 링크 컬럼. 풀블리드.
- **버튼**: Primary=INK 면+흰 텍스트(+우측 화살표 아이콘), Ghost=흰 면+`#C2C2C2` 테두리.
  라운드 10, 세로 패딩 14–16.
- **eyebrow(칩 라벨)**: SURF3 면, 999 라운드, SemiBold `#767676`, 작은 대문자 태그.
- **칩/필터칩**: 활성=INK 면+흰 글자, 비활성=흰 면+LINE 테두리.
- **배지**: 상태(완료/대기 등)는 INK 면(강조) 또는 SURF3 면+테두리(약). 색 사용 금지.

## 히어로
- **센터형**: eyebrow → 큰 H1(2줄, 중앙정렬) → 서브카피 → 버튼 2개(중앙) → (신뢰지표/이미지).
- **2단형**: 좌 텍스트(eyebrow·H1·본문·버튼·평점) + 우 이미지(FILL).
- 히어로 이미지는 컨테이너 1440 폭 또는 2단의 우측 고정폭.

## 카드
- **피처 카드**: 아이콘 타일(SURF2, 라운드 14, Phosphor 라인아이콘) + H3 + 설명. 3~4열 그리드.
- **상품/도서 카드**: 커버 이미지(FILL) + 카테고리 eyebrow + 하트 아이콘 + 제목 + 저자 +
  별점(벡터 별 5 + 점수/개수) + 가격(+원가 취소선/할인 배지).
- **통계(KPI) 카드**: 라벨 + 큰 수치 + 증감 배지(위 화살표) + 미니 스파크라인(작은 바 행).
- **플랜 카드(요금제)**: 이름+인기배지 · 큰 가격/월 · 설명 · CTA · 구분선 · 기능 체크리스트.
  추천 티어는 **다크 카드**로 강조.

## 데이터
- **테이블(clean)**: 헤더 행 `#FAFAFA`/`#F4F4F4` 면 · 셀 세로 가운데정렬 · 열 정렬 일관
  (텍스트 L, 숫자/상태 C) · 행 아래 1px `#F2F2F2` 구분선 · 상태는 배지. 라운드 14 카드로 감쌈.
  → **cleanTable 헬퍼**(figma-build.md) 사용. 고정폭 열 + FILL 열 혼용.
- **바 차트**: 카드 헤더(제목+기간 탭) · y축 라벨 · 가로 격자선 4~5 · 막대(최댓값 INK 강조) ·
  x축 라벨. 격자선/막대는 **고정폭 플롯 프레임**에 절대 배치(figma-build.md).
- **도넛/게이지**: `ellipse.arcData`로 링 세그먼트. 배경 링(LINE) + 전경 아크(INK, 0~pct) +
  중앙 % 텍스트.

## 폼
- **필드**: 라벨(작은 바/텍스트) + 입력 박스(흰 면, LINE 테두리, 라운드 8, 높이 42–44).
- **검색바**: 좌 돋보기 + 입력 + 우 검색 버튼(Primary).
- **토글**: pill 트랙(on=INK/off=`#D5D5D5`) + 흰 노브. 42×24.
- **체크박스/라디오**: 18px 사각(체크=INK 면)/원(라디오).
- **탭**: 하단 밑줄(활성 INK 2px). **아코디언/FAQ**: 질문 행 + 셰브론, 펼침 시 답변 문단.
- **페이지네이션**: 이전/다음 + 번호 버튼(활성 INK 면+흰 글자).
- **브레드크럼**: `홈 › 도서 › …` `#767676`, 구분 `›` `#B0B0B0`.

## 편집(아티클)
- **리딩 컬럼**: 760px 중앙(1440 안). 리드 문단(큰) · 소제목 · **풀 인용구**(상단 짧은 룰+중앙 큰 텍스트) ·
  **인라인 이미지+캡션** · 태그 · **작가 바이오 박스**.

## 모바일 변형
- GNB=로고+검색+햄버거. 사이드바→필터 버튼. 그리드 3열→2열, 2단→세로 스택.
- 상세엔 **스티키 하단 구매바**. 본문 텍스트는 반드시 FILL(줄바꿈).

## 웹 구조별 섹션 컴포넌트 (component page `1:7` 보드 13–16)
통상적인 웹사이트 구조(헤더·히어로·콘텐츠·푸터)별 변형 세트. 새 화면은 각 유형에서
하나를 골라 조합한다. 모두 무채색·라운드 8–16·1px 라인, 다크 변형은 `#141414`.

- **13 · 헤더 (Header)** — ① 기본형(로고+내비) · ② CTA 포함(로고+내비+다크버튼) ·
  ③ 로고 중앙+좌우 유틸 · ④ 검색 바+로그인/가입 · ⑤ 다크 헤더. 높이 76–84, 좌우 패딩 32,
  `SPACE_BETWEEN` 정렬.
- **14 · 히어로 (Hero)** — ① 센터형(eyebrow+H1+서브+버튼2) · ② 스플릿(텍스트+이미지 FILL) ·
  ③ 풀블리드 오버레이(다크 면+흰 텍스트) · ④ 검색/폼형(H1+검색필드+버튼).
- **15 · 콘텐츠 섹션 (Content)** — ① 피처 3열 그리드(FILL 카드) · ② 교차형(이미지+텍스트) ·
  ③ 통계 밴드(다크, 큰 수치×4) · ④ 로고 스트립(파트너 5) · ⑤ 고객 후기(중앙 인용+저자) ·
  ⑥ CTA 밴드(다크, 좌 헤드라인+우 버튼).
- **16 · 푸터 (Footer)** — ① 멀티컬럼(라이트, 로고+설명+링크 3열+하단 정책바) ·
  ② 심플 센터형(로고+내비+저작권) · ③ 뉴스레터 구독형(좌 구독폼+우 링크) · ④ 멀티컬럼(다크).

빌드는 auto-layout 기반(헤더/CTA/통계=`SPACE_BETWEEN`, 피처 카드=행 FILL, 본문 카피=FILL 줄바꿈).
각 보드는 세로 auto-layout 컬럼에 캡션+변형을 쌓고, 페이지 보드 열(01–12) 오른쪽에 이어 배치한다.
