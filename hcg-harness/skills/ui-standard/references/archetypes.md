# ax-wireframe — Archetypes (아키타입)

하이파이 기준(58:9)의 8대 페이지 유형. 새 화면은 브리프에 맞는 아키타입을 골라 **섹션 순서를
유지**하며 재현한다. 데스크톱(1920/1440)과 모바일(360)을 쌍으로 만든다.

## 공통 골격
`GNB → (브레드크럼) → 콘텐츠 섹션들 → CTA/뉴스레터 밴드 → 푸터`
밴드 배경은 풀블리드, 콘텐츠는 1440 컨테이너 중앙정렬.

## ① 홈 (마케팅)
GNB · 히어로(2단: 카피+이미지) · 신뢰 스트립 · 피처 3열 · 쇼케이스(2단 이미지+체크리스트) ·
통계 다크밴드(4) · 카드 그리드(도서/콘텐츠) · CTA · 푸터.

## 로우파이(구조) 아키타입 (37:8)
동일 골격을 회색 바/“이미지” 박스로 축약. 웹 17종 · 앱 16종 · 배너 9종.
- 앱 화면: 상태바 · 앱바(back) · 콘텐츠 · 바텀 탭. 폭 360.
- 배너: 히어로 1440×360 · 스트립 · 프로모 · 카드 · 스퀘어 · 버티컬 · 인앱 · 전면팝업(고정 규격).

  “관리/통계” → ⑦, “가격/플랜” → ②/⑧, “서비스 홍보” → ①/②.
