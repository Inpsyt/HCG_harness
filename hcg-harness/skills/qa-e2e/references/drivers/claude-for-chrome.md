# Driver — Claude for Chrome

사용자의 **실제 Chrome** 을 조작한다. 로그인 세션·확장·저장된 자격증명이 그대로 살아 있다.

**강점**: 인증 장벽이 높은 앱(OTP·SSO·결제·기기 인증)에서 사람이 인증을 통과시키고 나머지를
에이전트가 이어받을 수 있다. 실제 사용자가 보는 화면 그대로다.

**약점**: 사람이 붙어 있어야 한다. 헤드리스·CI 에서 못 쓴다. 반복 실행의 재현성이 낮다.

---

## 시작 전

1. **탭 상태 확인.** 사용자의 작업 탭이 열려 있다. 새 탭에서 시작하고, **남의 탭을 닫거나
   이동시키지 않는다**
2. **주소창이 대상 URL 인지 확인한다.** 운영 도메인이면 멈추고 확인받는다 (안전 규칙 1).
   비슷한 도메인(`app.example.com` vs `app-dev.example.com`)을 눈으로 구분한다
3. **프로필 확인.** 사용자가 이미 다른 계정으로 로그인돼 있을 수 있다. 어떤 계정으로 시작하는지
   먼저 화면에서 확인하고 `results.json` 에 적는다
4. **DevTools 를 열어둔다** — Network 탭. 증거의 대부분이 여기서 나온다

## 로그인 — 사람에게 넘기는 지점

```
1. 로그인 화면까지 이동한다
2. 비민감 필드(전화번호·학번·학교 선택)만 채운다
3. 사용자에게 넘긴다: "비밀번호/OTP 를 입력하고 로그인해 주세요. 되면 알려주세요."
4. 로그인 완료를 화면으로 확인한 뒤 재개한다
```

dev 우회 수단이 있으면(빠른 로그인 버튼, 고정 OTP, 인증 스킵) **그걸 먼저 안내한다** — 사람의
대기 시간을 줄인다.

**절대 하지 않는 것**: 비밀번호·OTP·카드번호 입력, 저장된 자격증명 읽기, 자동완성 값 꺼내기.

## 조작

- **실제 클릭·타이핑**을 쓴다. `document.querySelector(...).click()` 같은 DOM 직접 조작은
  이탈 감지·부정행위 감지·분석 이벤트를 우회하거나 반대로 오탐을 만든다
- 사람이 쓰는 속도로. 연속 클릭을 몰아치지 않는다
- 각 액션 후 화면이 바뀔 때까지 기다린 뒤 다음으로 간다
- **탭 포커스를 옮기지 않는다.** 응시 화면·시험 앱처럼 화면 이탈을 감지하는 앱에서는 다른 탭으로
  가는 것만으로 위반이 기록되고 강제 제출된다. 위반 시나리오를 **의도적으로 실행할 때만** 옮긴다
- 전체화면을 요구하는 앱이면 요청을 수락한다

## 증거 수집

| 무엇 | 어떻게 |
|---|---|
| 네트워크 | DevTools Network — 메서드·경로·상태코드·건수. 필터로 XHR/Fetch 만 |
| 서버 상태 되읽기 | 새 탭에서 GET API 를 직접 열어 응답 JSON 확인 |
| 콘솔 에러 | DevTools Console |
| 화면 문구 | 그대로 인용. 스크린샷보다 텍스트가 리포트에서 유용하다 |
| 스크린샷 | 실 PII 가 없을 때만 |

**되읽기가 가장 강한 증거다.** "저장됨" 토스트를 본 뒤 GET 으로 실제 저장 여부를 확인하면
`pass` 의 근거가 확실해진다.

## 사람과의 협업 루프

브라우저를 사람과 공유하므로 **말없이 오래 조작하지 않는다**:

- 스위트 하나가 끝날 때마다 무엇을 했고 무엇이 나왔는지 한 줄로 알린다
- 사람 입력이 필요한 지점은 미리 예고한다 ("다음 단계에서 결제창이 뜹니다")
- 파괴적 액션 직전에 멈추고 확인받는다
- 사용자가 브라우저를 쓰려고 하면 양보한다

## 이 드라이버에서 흔한 함정

- **사용자가 중간에 탭을 바꿨다.** 화면 상태가 예상과 다르면 조작을 계속하지 말고 현재 화면을
  먼저 확인한다. 엉뚱한 페이지에서 클릭하면 실제 데이터를 건드린다
- **확장 프로그램 간섭.** 광고 차단기·번역기가 DOM 을 바꿔 셀렉터가 안 맞을 수 있다. 앱 버그로
  단정하기 전에 시크릿 창에서 재확인한다
- **자동완성.** 폼 필드가 이전 값으로 자동 채워질 수 있다. 입력 전에 필드를 비운다
- **캐시·기존 세션.** "로그아웃 상태에서 접근" 시나리오는 시크릿 창이 필요하다
- **재현성.** 이 드라이버의 결과는 사람의 조작이 섞여 있다. `results.json` 의 `steps` 를 성실히
  적어야 나중에 재현할 수 있다
