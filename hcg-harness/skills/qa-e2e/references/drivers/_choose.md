# 드라이버 선택

브라우저를 무엇으로 몰지 정한다. **언어·프레임워크와 무관**하다 — 어떤 스택이든 같은 표를 쓴다.

---

## 1. 무엇이 실제로 가능한지 확인한다

추측하지 말고 확인한다:

| 확인 | 방법 |
|---|---|
| **Claude for Chrome** | 브라우저 조작 도구가 현재 세션에 노출돼 있는가 (탭 열기·클릭·읽기) |
| **Playwright MCP** | `mcp__playwright__*` 계열 도구가 있는가. 없으면 `ToolSearch` 로 조회 |
| **Chrome DevTools MCP** | `mcp__chrome-devtools__*` — 네트워크·성능 추적에 강함 |
| **로컬 Playwright** | `npx playwright --version` · `ls node_modules/.bin/playwright` |

## 2. 선택 표

| 상황 | 드라이버 | 읽을 문서 |
|---|---|---|
| 사람이 옆에 있고 **실제 로그인 세션·OTP·결제**가 필요 | **Claude for Chrome** | `claude-for-chrome.md` |
| MCP 연결됨 · 반복 실행 · 구조화된 스냅샷/네트워크 로그가 필요 | **Playwright MCP** | `playwright-mcp.md` |
| 둘 다 없고 Node 프로젝트이거나 Node 를 쓸 수 있음 | **로컬 Playwright** | `playwright-local.md` |
| 브라우저 자체가 불가 (헤드리스 서버, 도구 없음) | **없음** | 아래 §브라우저 불가 |

**둘 이상 가능하면**: 인증 장벽이 높은 앱(OTP·SSO·결제)은 Claude for Chrome, 그 외 반복성이
중요한 검증은 Playwright MCP 를 기본으로 제안하고 사용자에게 확인받는다.

**중간에 바꿔도 된다.** 로그인만 Chrome 으로 사람이 통과시키고 이후를 Playwright 로 이어받는 구성이
가장 실용적일 때가 많다. 바꿨으면 `results.json` 의 해당 케이스 `note` 에 적는다.

## 3. 어떤 드라이버든 지키는 것

### 증거 수집
- **네트워크를 본다.** 화면의 "저장되었습니다"는 저장의 증거가 아니다. 요청 URL·메서드·상태코드를
  기록하고, 중요한 건 GET 으로 되읽어 확인한다
- 콘솔 에러를 수집한다. 화면이 멀쩡해 보여도 콘솔에 예외가 쌓이고 있을 수 있다
- 판정의 근거가 된 **화면 문구를 그대로 인용**한다. "정상 표시됨"이 아니라 실제 텍스트

### 조작 방식
- **실제 UI 클릭 위주로, 사람이 쓰는 속도로.** JS 로 DOM 을 직접 조작하거나 초당 여러 번 클릭하면
  앱의 이탈 감지·부정행위 감지·rate limit·낙관적 락에 걸려 **테스트가 앱 상태를 오염**시킨다.
  실제로 이렇게 만들어진 "버그"가 리포트에 올라간 사례가 있다
- 각 액션 후 **결과가 반영될 때까지 기다린다.** 고정 sleep 보다 조건 대기(요소 등장·네트워크 완료)
- 셀렉터는 사용자가 보는 것 기준으로 — 접근 가능 이름·라벨 텍스트·role. CSS 클래스 해시는 쉽게 깨진다

### 세션 격리
영역별 세션 저장소가 다르면(`discovery.md` §3) **영역마다 별도 컨텍스트/프로필**을 쓴다.
같은 브라우저에서 관리자 로그인 후 사용자 로그인을 하면 서로를 덮어써 원인 불명 실패가 반복된다.

### 안전
- 자격증명 대리입력 금지 — SKILL.md 안전 규칙 2
- 파괴적 액션 사전 확인 — 안전 규칙 3
- 실 PII 스크린샷 금지 — 안전 규칙 4

## 브라우저 불가일 때

E2E 를 통째로 버리지 않는다:

1. **API 레이어로 대체 가능한 시나리오**는 `curl`/HTTP 클라이언트로 검증하고, `note` 에
   "화면 미검증, API 레벨만 확인"이라고 명시한다. 상태는 `pass` 가 아니라 `blocked` 가 맞는 경우가
   많다 — 화면 시나리오였다면 화면을 못 본 것이다
2. 러너 레이어(단위·통합)는 정상 수행한다
3. 리포트 메타의 `driver` 에 `"없음 — 브라우저 도구 미가용"` 을 적고, 영향받은 케이스를 명시한다

**"브라우저가 없어서 그냥 통과로 뒀다"는 하지 않는다.**
