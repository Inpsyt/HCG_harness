# 0. ⛔ 안전 규칙

1. 작업 대상은 오직 `{baseUrl}`.
2. **운영 도메인(`{운영URL}`)에서는 어떤 조작도 금지.** 실사용자 데이터가 훼손된다.
   조회조차 개인정보 노출이므로 지양.
3. 시작 전 **주소창이 대상 URL 인지 확인**. 아니면 멈추고 확인받는다.
4. 자동화 에이전트는 **비밀번호·OTP·결제정보를 대신 입력하지 않는다** — 로그인 화면까지 이동 +
   비민감 필드만 채우고 인증은 사용자에게 넘긴다. dev 우회 수단이 있으면 그걸 우선 안내.
5. 파괴적 액션(삭제·환불·전체취소·초기화)은 실행 전 확인받는다.
6. 실 사용자 PII 가 보이면 스크린샷 저장 금지, 리포트에 실명 미기재.

# 5. 결과 기록

실행 결과는 `qa/results.json` 에 케이스마다 append 하고, 리포트는 렌더러로 생성한다.

```bash
node "<qa-e2e 스킬 폴더>/scripts/render-report.mjs" qa/results.json
# → qa/report.md, qa/report.html
```

발견한 이슈는 `results.json` 의 `issues[]` 에 넣고, 이 문서의 회귀 스위트(G)에도 항목을 추가해
다음 회차부터 자동으로 재검증되게 한다.
